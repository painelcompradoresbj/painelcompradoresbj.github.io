# Painel de obras por comprador

Painel com mapa da divisão de obras por comprador (dados do SIGO).

- `index.html` — a página
- `dados.json` — linhas do relatório do SIGO e tabelas de Cadastros (fases, compradores, regiões, regras por código)
- `areas.json` — contornos do mapa (estados; SP e MG divididos por região)
- `municipios.json` — coordenadas dos municípios

Para atualizar os dados, troque o `dados.json` (gerado a partir da planilha `Painel_Obras_por_Comprador.xlsx`).
